# PaleoTrunfo: A Jornada dos Gigantes

Jogo educativo de cartas estilo Super Trunfo com 48 espécies pré-históricas.
Compara atributos (altura, peso, comprimento, velocidade, antiguidade) em rodadas
contra o "Robô Amigo", com modo simplificado, leitura em voz alta, enciclopédia
e paleoarte científica em cada carta.

Site publicado: https://edvaine2013.github.io/paleotrunfo/

Créditos das paleoartes: TotalDino, Dmitry Bogdanov, Julio Lacerda, Mark P. Witton,
Connor Ashbridge, Emily Willoughby, Fred Wierum, Maurício Antón, Nobu Tamura,
Leví Martínez-Reza, Jeff Martz/NPS e outros, via Wikimedia Commons
(CC BY, CC BY-SA e CC0). Autoria indicada em cada carta.
