# PaleoTrunfo: A Jornada dos Gigantes

Jogo educativo de cartas estilo Super Trunfo com 48 dinossauros e outros gigantes pré-históricos.
Compara atributos (tamanho, peso, velocidade, ferocidade) em rodadas contra o "Robô Amigo",
com modo simplificado, leitura em voz alta e galeria de espécies.

Site publicado: https://edvaine2013.github.io/paleotrunfo/
